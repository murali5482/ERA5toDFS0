# ERA5 TimeSeries Viewer - Build Instructions for Developers

## Quick Reference Card

Save this file - it has everything you need to build the standalone executable.

## System Requirements

Before starting, ensure you have:
- Windows 10 or later (64-bit)
- Python 3.9 or later installed
- At least 5GB free disk space
- Internet connection

## Step-by-Step Build Instructions

### STEP 1: Prepare Environment (5 minutes)

Open Command Prompt and run:

```batch
REM Navigate to the ERA5 folder
cd C:\Users\[YourUsername]\Documents\GitHub\ERA5

REM Create virtual environment
python -m venv build_env

REM Activate virtual environment
build_env\Scripts\activate

REM You should see (build_env) at start of command line
```

### STEP 2: Install Dependencies (3 minutes)

```batch
REM Install PyInstaller and all dependencies
pip install --upgrade pip
pip install -r requirements_build.txt

REM This downloads and installs all needed packages (~1.5GB)
REM May take 2-5 minutes depending on internet speed
```

### STEP 3: Build Executable (10 minutes)

```batch
REM Build the standalone executable
pyinstaller era5_build.spec

REM Wait for completion... you should see:
REM "successfully created dist/ERA5_TimeSeries_Viewer.exe"
```

### STEP 4: Verify Build (5 minutes)

```batch
REM Test the executable
dist\ERA5_TimeSeries_Viewer.exe

REM The application window should open
REM Close the application to verify it works
```

### STEP 5: Create Installer (5 minutes, OPTIONAL)

To create a professional Windows installer:

**5a. Install NSIS**
- Download from: https://nsis.sourceforge.io/
- Run the installer
- Accept default options

**5b. Build installer**
```batch
"C:\Program Files (x86)\NSIS\makensis.exe" era5_installer.nsi

REM Creates: ERA5_TimeSeries_Viewer_Setup.exe
```

## Troubleshooting Build

### Problem: "pyinstaller not found"
**Solution:** Ensure you activated virtual environment (Step 1)
```batch
build_env\Scripts\activate
```

### Problem: "No module named tkinter"
**Solution:** This is included with Python, but ensure it's installed
```batch
python -m pip install tk
```

### Problem: Build takes forever
**Solution:** This is normal - PyInstaller bundles everything (~1-2 hours first time)
- Go get a coffee ☕
- Let it complete

### Problem: Executable is 1GB+
**Solution:** This is normal with PyInstaller bundled Python
- Includes full Python runtime + all libraries
- Can't be reduced significantly without code optimization

### Problem: "Access denied" error
**Solution:** Run Command Prompt as Administrator
- Right-click cmd.exe
- Select "Run as administrator"

### Problem: Build says "completed" but I don't see exe
**Solution:** Check the `dist/` folder
```batch
dir dist\
REM Should show ERA5_TimeSeries_Viewer.exe
```

## Complete Build Script (Copy-Paste Ready)

Save as `build_all.bat` in ERA5 folder:

```batch
@echo off
echo Building ERA5 TimeSeries Viewer...
echo.

cd /d "%~dp0"

echo Step 1: Creating virtual environment...
python -m venv build_env
call build_env\Scripts\activate.bat

echo Step 2: Installing dependencies...
pip install --upgrade pip
pip install -r requirements_build.txt

echo Step 3: Building executable...
pyinstaller era5_build.spec

echo Step 4: Creating installer...
"C:\Program Files (x86)\NSIS\makensis.exe" era5_installer.nsi

echo.
echo ===== BUILD COMPLETE =====
echo Executable: dist\ERA5_TimeSeries_Viewer.exe
echo Installer:  ERA5_TimeSeries_Viewer_Setup.exe
echo.
pause
```

Run with: `build_all.bat`
